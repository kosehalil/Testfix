Selenium Test Otomasyonu

Selenium, test otomasyonu, mülakat soruları ve gerçek proje deneyimleri

Selenium Nedir?

Selenium, web uygulamalarını otomatik test etmek için kullanılan açık kaynaklı bir test otomasyon aracıdır.

  • Web tabanlı testler
  • Java, Python, C# desteği
  • Cross-browser testing
Selenium WebDriver

WebDriver, tarayıcıyı doğrudan kontrol ederek gerçek kullanıcı davranışlarını simüle eder. 

                        driver.findElement(By.id("email"))
                        .sendKeys("deneme@denemegmail.com");
Locator Stratejileri

Sağlam testler için doğru locator kullanımı kritik öneme sahiptir.

  • id (en iyi cünkü id tektir)
  • name
  • cssSelector
  • xpath
Wait Kullanımı (Implicit & Explicit)

Thread.sleep yerine WebDriverWait kullanmak test stabilitesini artırır. 

                        WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
                        wait.until(ExpectedConditions
                        .visibilityOfElementLocated(By.id("login")));
Selenium + TestNG

TestNG ile test senaryoları daha düzenli ve yönetilebilir hale gelir.

  • @BeforeMethod
  • @Test
  • @AfterMethod
  • Parallel Test

QA Test Mülakat Soruları

Kalite Güvence (QA), yazılım geliştirme süreçlerinin olmazsa olmaz bir parçasıdır. QA Test Uzmanı, Kalite Mühendisi veya Test Otomasyon Mühendisi pozisyonları için yapılan mülakatlarda, adayların test metodolojileri, hata yönetimi, otomasyon araçları ve yazılım geliştirme süreçlerine hakimiyeti detaylı bir şekilde incelenir.

Bu yazıda, QA test mülakatlarında karşınıza çıkabilecek 10 kritik soruyu ve bunlara nasıl yanıt verebileceğinizi detaylı şekilde ele aldık.

1. Yazılım Testinin Temel Amaçları Nelerdir?

  • Hataları tespit etmek
  • Kaliteyi ve kullanıcı deneyimini artırmak
  • Riskleri azaltmak
  • Regülasyon ve standartlara uyumu sağlamak

2. Black Box Test ve White Box Test Arasındaki Farklar

Black Box Test: Kod yapısı bilinmeden giriş ve çıkışlara odaklanır.
White Box Test: Kod yapısı ve algoritmalar üzerinden yapılan testlerdir.
Gray Box Test: Her iki yaklaşımın birleşimidir (ör. API testleri).

3. Test Senaryosu ve Test Case Arasındaki Fark

Test senaryosu, yüksek seviyeli test amacını ifade ederken, test case testin adım adım nasıl yapılacağını tanımlar. 

	           	Kullanıcı adı: deneme@gmail.com
		        Şifre: 123456
		        Giriş Yap → Başarılı mesaj doğrulanır

4. Regression Test Nedir?

Yeni bir geliştirme veya hata düzeltmesinden sonra, mevcut fonksiyonların bozulmadığını doğrulamak için yapılır.

5. Selenium Nedir?

Selenium, web uygulamalarını otomatik test etmek için kullanılan açık kaynaklı bir test otomasyon aracıdır.

6. Bug Lifecycle (Hata Yaşam Döngüsü)

New → Assigned → In Progress → Fixed → Tested → Closed

7. Performans Testi Türleri

  • Load Test
  • Stress Test
  • Endurance Test

8. Agile & Scrum’da QA’nın Rolü

QA ekipleri sprint boyunca test, otomasyon ve kalite güvencesinden sorumludur.

9. API Testi Nasıl Yapılır?

Manuel testler Postman ile, otomasyon testleri ise RestAssured, Karate ve SoapUI gibi araçlarla yapılır.

10. Page Object Model (POM) Nedir?

Page Object Model, test kodlarını daha okunabilir, sürdürülebilir ve bakımı kolay hale getiren bir tasarım desenidir.
